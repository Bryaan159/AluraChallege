# 📊 Telecom X - Análisis de Evasión de Clientes (Churn)

Este repositorio contiene el análisis exploratorio de datos (EDA) del proyecto **"Churn de Clientes"** para **Telecom X**, una empresa de telecomunicaciones que enfrenta una alta tasa de cancelaciones. El objetivo es identificar los factores que influyen en la evasión de clientes y proporcionar insights estratégicos que permitan mejorar la retención.

---

## 🧠 Objetivo

Comprender el comportamiento de los clientes que cancelan el servicio (`Churn`) y encontrar patrones relevantes que sirvan de base para modelos predictivos y estrategias comerciales.

---

## 🗂️ Contenido

- **Carga de datos desde API (JSON)**
- **Limpieza y transformación de datos**
- **Análisis exploratorio de datos (EDA)**
- **Visualización de variables categóricas y numéricas**
- **Insights y patrones de evasión**
- **Recomendaciones estratégicas**

---

## 🛠️ Tecnologías utilizadas

- Python 🐍
- Pandas 📊
- Matplotlib 📈
- Seaborn 🎨
- Jupyter Notebook 📓

---

## 📌 Resultados clave

- La tasa de evasión es de aproximadamente **26.5%**.
- Clientes con **contrato mensual** son los más propensos a cancelar.
- La **permanencia corta** (bajo `tenure`) está altamente correlacionada con evasión.
- Clientes que **gastan menos en total** también muestran mayor churn.
- Métodos de pago como **débito automático** están asociados con mayor fidelidad.

---

## ✅ Recomendaciones

- Incentivar **contratos anuales o bianuales**.
- Detectar y atender a **clientes nuevos** con promociones o seguimiento personalizado.
- Fomentar el uso de **métodos de pago automáticos**.
- Crear campañas de fidelización según el perfil del cliente.
