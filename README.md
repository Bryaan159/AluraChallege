# Análisis de Ventas - Alura Store

## Propósito del análisis

Este proyecto tiene como objetivo analizar el desempeño de las cuatro tiendas de la cadena Alura Store para ayudar al Sr. Juan a decidir cuál tienda debería vender para iniciar un nuevo emprendimiento. Se examinaron datos de ventas, ingresos, reseñas de clientes y costos de envío para identificar la tienda menos eficiente y presentar una recomendación basada en datos.

---

## Estructura del proyecto

- `notebook.ipynb`: Notebook de Jupyter/Colab donde se realiza todo el análisis, incluyendo carga de datos, procesamiento, visualizaciones y conclusiones.
- `data/`: Carpeta que puede contener los archivos CSV de las tiendas (opcional si se usan URLs).
- `README.md`: Este archivo con la descripción general del proyecto.

---

## Ejemplos de gráficos e insights obtenidos

- **Ingresos Totales por Tienda**: gráfico de barras que muestra cuánto dinero generó cada tienda.
- **Top 5 Categorías Más Vendidas**: gráfico de pastel que muestra las categorías de productos con mayor demanda.
- **Calificación Promedio por Tienda**: gráfico de barras que muestra la satisfacción promedio de los clientes.
- **Productos Más y Menos Vendidos**: gráficos de barras para identificar los productos con mayor y menor éxito.
- **Costo Promedio de Envío por Tienda**: gráfico de barras que indica qué tienda tiene costos de envío más altos.
